# PLEGEM interactivo

Recurso interactivo sobre el Plan Estatal General de Emergencias de Protección Civil (PLEGEM).

> **EN** · Interactive learning resource on Spain's national civil-protection emergency plan (PLEGEM).

🔗 **Demo:** [plegem.sanidadedtech.es](https://plegem.sanidadedtech.es/)

## Para quién es

Alumnado de Coordinación de Emergencias y Protección Civil.

## Qué incluye

- Qué es y para qué sirve el PLEGEM
- Quién decide en cada nivel territorial
- Cómo circula la información en una emergencia
- Movilización de recursos y fases del plan

## Tecnología

- Página única en HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.
- Diseño adaptable a móvil.
- Publicado con GitHub Pages.
- Desarrollado mediante *AI-driven prototyping*: diseño pedagógico y clínico propio, construcción asistida por IA y revisión manual.

## Uso

Abre la demo en el navegador o descarga `index.html` y ábrelo directamente: no necesita instalación.
